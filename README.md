
## ⏰ Digital Clock

A simple and modern **Digital Clock built with Python and Tkinter**. The clock displays the current time in real time with a clean **dark-themed interface** and bright **green digital-style text**.

The project is designed to be beginner-friendly while demonstrating important Python concepts such as **GUI development, functions, time handling, and continuous updates**. The clock automatically refreshes every second, ensuring that the displayed time stays accurate without requiring manual input.

### ✨ Features

* 🕐 Displays the current time in real time
* 🌙 Dark-themed interface
* 🟢 Green digital-style time display
* 🔄 Automatically updates every second
* 🐍 Built using Python
* 🖥️ Simple and beginner-friendly GUI
* ⚡ Lightweight and easy to run

### 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Datetime / Time module**

This project is a small but practical example of how Python can be used to create interactive desktop applications.
